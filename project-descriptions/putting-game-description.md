## **Mechatronics Capstone: Interactive Putting Game**

**Overview** For my junior-year Mechatronics final project, I designed and programmed an interactive, arcade-style golf putting game. The project required integrating physical hardware sensors with custom software logic to create a responsive, sensor-driven user experience.

**Software & Firmware**

* **Full-Stack Development:** Developed the complete software architecture from scratch. I utilized the **Arduino IDE** to program the microcontroller, handle sensor data acquisition, and manage the hardware logic.  
* **Custom Interface:** Built the visual front-end and game state logic using **Processing** to create a seamless graphical user interface.

**Gameplay Mechanics & Features**

* **Time-Trial Challenge:** The core objective challenges players to successfully putt the golf ball into the target cup before a strict time limit expires.  
* **Live Data Telemetry:** Engineered a real-time digital scoreboard that continuously tracks and updates key gameplay metrics, including time remaining, current score, putting accuracy percentage, and the all-time high score.
